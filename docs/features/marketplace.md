# 마켓플레이스 기능 기획

## 개요

생물 개체 및 사육용품 거래/경매 플랫폼

---

## 상품 종류

| 카테고리 | 설명 |
|----------|------|
| 생물 개체 | 동식물 개체 거래 |
| 사육용품 | 사육장, 장비, 액세서리 |
| 먹이/영양제 | 먹이, 영양제, 첨가제 |

---

## 판매자

### 등록 방식

- 승인제: 관리자 승인 후 판매 가능
- 판매자 프로필 등록 필수

### 판매자 정보

- 사업자/개인 구분
- 연락처
- 판매 이력
- 신뢰도 점수

---

## 거래 방식

### 직거래

- 고정가 판매
- 가격 협상 가능 옵션

### 경매

| 방식 | 설명 |
|------|------|
| 기본 경매 | 시작가 + 입찰 + 마감 |
| 즉결 경매 | 기본 + 즉시구매가 설정 |
| 역경매 | 구매자가 희망가 제시 |
| 비공개 경매 | 입찰가 비공개 |

---

## 결제

### 플랫폼 결제

- PG 연동 (카드, 계좌이체 등)
- 결제 내역 관리
- 정산 시스템

---

## 배송

### 판매자 직접 처리

- 판매자가 배송 방법 선택
- 송장번호 등록
- 배송 상태 업데이트

---

## 리뷰/신뢰도

### 리뷰 시스템

- 별점 (1~5)
- 텍스트 리뷰
- 사진 리뷰
- 판매자 답글

### 신뢰도 시스템

- 거래 완료율
- 평균 평점
- 응답률
- 신뢰도 점수 산출

---

## 분쟁 처리

### 중재 시스템

- 분쟁 신고 접수
- 관리자 중재 개입
- 증거 자료 제출
- 처리 결과 통보

---

## 모듈별 역할

| 모듈 | 기능 |
|------|------|
| API | 상품 CRUD, 경매 API, 결제 연동, 주문 관리, 정산 API |
| ADMIN | 판매자 승인, 상품 관리, 분쟁 처리, 정산 관리 |
| WEB | 상품 등록/조회, 경매 참여, 결제, 주문 조회, 리뷰 작성 |
