# 건강 진단 기능 기획

## 개요

AI 기반 개체 건강 상태 분석 및 종합 케어 가이드 제공

---

## 진단 입력

### 입력 방식

- 사진 업로드: 개체 사진 촬영/업로드
- 증상 설명: 텍스트로 증상 상세 기술
- 혼합 입력: 사진 + 설명 동시 제출

### 입력 항목

- 개체 선택 (사육환경 관리 연동)
- 사진 (다중 업로드 가능)
- 증상 설명
- 발견 시점
- 기타 특이사항

---

## AI 분석

### 분석 결과 제공

| 항목 | 설명 |
|------|------|
| 건강 상태 | 정상/주의/위험 등급 |
| 예상 증상 | 증상명 및 설명 |
| 원인 분석 | 가능한 원인 목록 |
| 해결책 | 대응 방법 및 치료법 |
| 예방법 | 재발 방지 가이드 |
| 관련 제품 | 치료/예방 관련 제품 추천 |

---

## 건강 모니터링

### 스마트 모니터링

- 사육환경 데이터 기반 건강 위험 예측
- 이상 징후 감지 시 사전 알림
- 정기 건강 체크 알림

### 건강 이력 관리

- 진단 이력 저장 및 조회
- 사육환경 관리와 통합
- 건강 상태 추이 그래프

---

## 질병 정보 DB

### 구성

- 종별 주요 질병/증상 정보
- 원인 및 치료법
- 예방법

### 커뮤니티 연동

- 커뮤니티 건강 관련 사례 연결
- 유사 증상 게시글 추천
- 경험 공유 유도

---

## 모듈별 역할

| 모듈 | 기능 |
|------|------|
| API | 진단 요청 API, AI 분석 연동, 질병 DB API, 건강 이력 API |
| ADMIN | 질병 DB 관리, AI 모델 관리, 진단 통계 |
| WEB | 진단 요청 UI, 결과 조회, 건강 이력, 질병 정보 검색 |
