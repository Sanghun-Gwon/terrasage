# 커뮤니티 기능 기획

## 개요

사육자 간 정보 공유 및 소통을 위한 커뮤니티 플랫폼

---

## 게시판 구성

### 주제별 게시판

| 게시판 | 설명 |
|--------|------|
| 사육팁/노하우 | 사육 경험 및 팁 공유 |
| 질문/답변 | Q&A 게시판 |
| 자랑/인증 | 개체 사진 공유 |
| 자유게시판 | 일반 소통 |

### 게시글 형식

- 텍스트 게시글
- 이미지 게시글 (갤러리)
- 혼합 형식 지원

---

## 상호작용

### 댓글/반응

- 댓글 및 대댓글
- 좋아요
- 북마크
- 신고

### 팔로우/구독

- 사용자 팔로우
- 게시판 구독
- 키워드 구독

---

## 회원 등급

### 활동 기반 등급 시스템

- 활동량(글/댓글/좋아요)에 따른 등급 상승
- 등급별 배지 표시
- 판매자/관리자 별도 표시

---

## 검색

### 검색엔진 스타일

- 제목/내용 텍스트 검색
- 게시판 필터
- 작성자 필터
- 통합 검색 결과 (검색엔진처럼 동작)

---

## 알림

### 풀 알림 시스템

- 내 글 댓글/답글 알림
- 팔로우 사용자 새 글 알림
- 멘션 알림
- 인기글 알림
- 구독 키워드 알림

---

## 모듈별 역할

| 모듈 | 기능 |
|------|------|
| API | 게시글 CRUD, 댓글, 좋아요, 팔로우, 검색, 알림 API |
| ADMIN | 게시판 관리, 신고 처리, 회원 등급 관리 |
| WEB | 게시판 UI, 글 작성/조회, 알림 센터, 마이페이지 |
