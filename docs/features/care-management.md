# 개인 사육환경 관리 기능 기획

## 개요

사용자가 자신의 사육 개체와 환경을 등록하고, 데이터를 기록/시각화하며, AI 기반 가이드를 받는 기능

---

## 개체 등록

### 등록 방식

- 백과사전 연동: 종 선택 후 개체 등록
- 직접 입력: 사용자가 종/이름 직접 입력

### 관리 단위

- 개별 관리: 개체별 독립 페이지
- 그룹 관리: 사육장/수조 단위 그룹화

---

## 데이터 기록

### 기록 방식

- 수동 입력: 사용자 직접 수치 입력
- IoT 연동: 센서 디바이스 자동 수집

### 기록 항목 (분류별 상이)

| 분류 | 항목 |
|------|------|
| 공통 | 온도, 습도, 먹이, 광량 |
| 식물 | 토양 농도(pH 등), 물주기 |
| 어류 | 수질 농도(pH, 암모니아 등), 수온 |
| 파충류/동물 | 탈피 기록, 번식 기록, 체중 |

---

## 시각화

### Grafana 스타일 대시보드

- 종합 대시보드
- 개별 수치 차트 (라인, 바)
- 트렌드 분석
- 개체 간 비교 차트
- 적정 수치 범위 표시

---

## 알림 시스템

### 스마트 알림

- 먹이/물주기 스케줄 알림
- 임계값 이상 범위 경고
- AI 패턴 기반 예측 알림

---

## AI 기능

### 세팅 가이드

- 백과사전 기반 권장 수치 제공
- 개인 데이터 학습 후 개인화 추천

### 추천 데이터 소스

| 소스 | 설명 |
|------|------|
| 개인 | 사용자 본인 기록 데이터 |
| 커뮤니티 | 대중적 평균 수치 |
| 전문가 | 판매자 등록 회원 데이터 |

---

## 데이터 공유

### 공유 정책

- 기본 비공개
- 사용자 선택적 공개
- 커뮤니티 공유 시 AI 학습 데이터로 활용

---

## 모듈별 역할

| 모듈 | 기능 |
|------|------|
| API | 개체 CRUD, 데이터 기록 API, IoT 연동, AI 추천 API |
| ADMIN | 전체 사용자 데이터 모니터링, AI 학습 데이터 관리 |
| WEB | 개체 등록, 데이터 입력, 대시보드, 알림 설정 |
