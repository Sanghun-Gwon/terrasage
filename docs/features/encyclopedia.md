# 백과사전 기능 기획

## 개요

생물 정보를 생물학적 분류 체계에 따라 정리하고 검색/조회하는 기능

---

## 분류 체계

### 생물학적 분류 (Taxonomic Rank)

계(Kingdom) → 문(Phylum) → 강(Class) → 목(Order) → 과(Family) → 속(Genus) → 종(Species)

### 아종/변이 관리

- 부모 종 페이지 하위에 목록 표시
- 클릭 시 상세 페이지로 이동
- 검색 시 아종/변이 단위까지 포함

---

## 개체 정보 구성

### 기본 정보

| 항목 | 설명 |
|------|------|
| 일반명 | 통용되는 이름 |
| 학명 | 학술적 명칭 |
| 설명 | 개체 소개 |

### 사육 정보

| 항목 | 설명 |
|------|------|
| 사육 난이도 | 1~10 (1-4: 쉬움, 5-7: 보통, 8-10: 어려움) |
| 적정 온도 | 범위 (min~max) |
| 적정 습도 | 범위 (min~max) |
| 먹이 | 종류 및 급여 주기 |
| 광량 | 필요 조도 |
| 수명 | 평균 수명 |
| 크기 | 성체 기준 |
| 서식지 | 자연 서식 환경 |
| 번식 정보 | 번식 조건 및 방법 |

### 이미지

- 갤러리 형식 (다중 이미지)
- 카테고리별 분류 (전체샷, 클로즈업, 서식환경 등)
- 대표 이미지 지정

---

## 검색 기능

### 고급 검색

- 이름/학명 텍스트 검색
- 분류 필터 (계/문/강/목/과/속)
- 난이도 필터
- 사육 조건 필터 (온도, 습도 범위)
- 조건 조합 검색
