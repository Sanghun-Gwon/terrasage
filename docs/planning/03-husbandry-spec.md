## 2. 화면별 상세 기능

### HUSB-01: 내 생물 목록 (대시보드)

**목적**: 내가 사육 중인 생물 전체를 한눈에 파악하고 빠르게 관리 진입

**UI 구성 요소**:
- 생물 카드 그리드 (사진, 이름, 종명, 마지막 급이일, 상태 배지)
- 상태 배지: 🟢 정상 | 🟡 급이 필요 | 🔴 주의 필요
- "새 생물 등록" 버튼
- 간단 통계: 총 보유 수, 오늘 급이 대상, 탈피 예정

**기능 상세**:

| 기능 ID | 기능명 | 설명 | MVP |
|---------|--------|------|-----|
| HUSB-01-F01 | 생물 카드 뷰 | 카드형 목록, 사진+요약정보 | ✅ |
| HUSB-01-F02 | 상태 알림 배지 | 급이/탈피 주기 기반 자동 상태 표시 | ✅ |
| HUSB-01-F03 | 빠른 급이 체크 | 카드에서 바로 "오늘 급이 완료" 체크 | ✅ |
| HUSB-01-F04 | 정렬/필터 | 종별, 상태별, 등록순 | ✅ |
| HUSB-01-F05 | 대시보드 요약 | 보유 수, 오늘 할 일 카운트 | ✅ |
| HUSB-01-F06 | 위젯형 알림 | 오늘의 할 일 푸시알림 | 2차 |

---

### HUSB-02: 생물 등록

**목적**: 새로운 사육 생물을 시스템에 등록

**등록 폼 필드**:

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 종 선택 | 백과사전 연동 검색 | ✅ | 백과사전의 종 프로필 연결 |
| 이름 | 텍스트 | ✅ | 개체 이름 (별명) |
| 성별 | 선택 (수/암/미확인) | ✅ | |
| 입양일 | 날짜 | ✅ | |
| 출생일 | 날짜 | | 알 수 있는 경우 |
| 입양 경로 | 선택 (분양/입양/자가번식/기타) | | |
| 모프/품종 | 백과사전 모프 연동 | | |
| 사진 | 이미지 업로드 | | 대표 사진 |
| 체중 | 숫자 (g) | | 등록 시 초기값 |
| 체장 | 숫자 (cm) | | 등록 시 초기값 |
| 메모 | 텍스트 | | 자유 기록 |

**기능 상세**:

| 기능 ID | 기능명 | 설명 | MVP |
|---------|--------|------|-----|
| HUSB-02-F01 | 종 검색 연동 | 백과사전에서 종 선택 → 사육가이드 자동 연결 | ✅ |
| HUSB-02-F02 | 사진 업로드 | 대표 사진 1장 (다중 사진은 2차) | ✅ |
| HUSB-02-F03 | 기본 급이 주기 설정 | 종별 권장 주기 자동 세팅, 수동 변경 가능 | ✅ |
| HUSB-02-F04 | 사육장 정보 입력 | 사육장 타입, 크기 (선택) | 2차 |

### HUSB-03: 생물 상세 (개별 관리 홈)

**목적**: 개별 생물에 대한 모든 관리 정보를 탭으로 접근

**UI 구성 요소**:
- 헤더: 생물 사진, 이름, 종명, 나이, 성별
- 요약 카드: 마지막 급이 D+N, 마지막 탈피 D+N, 현재 체중
- 탭: 사육일지 | 환경로그 | 성장기록 | 건강기록
- 빠른 액션 버튼: "급이 기록", "환경 기록", "메모 추가"

---

### HUSB-04: 사육 일지

**기록 항목**:

| 탈피 | 완전/부분/미탈피, 상태 메모 | 탈피 주기 자동 계산 |
| 배변 | 상태 (정상/이상), 메모 | |
| 수분 | 급수/분무/목욕 여부 | |
| 일반 메모 | 자유 텍스트, 사진 첨부 | |

**기능 상세**:

| 기능 ID | 기능명 | 설명 | MVP |
|---------|--------|------|-----|
| HUSB-04-F01 | 빠른 기록 | 타입 선택 → 간편 입력 (1탭 기록) | ✅ |
| HUSB-04-F02 | 타임라인 뷰 | 날짜순 기록 타임라인 | ✅ |
| HUSB-04-F03 | 필터 | 기록 타입별 필터 (급이만, 탈피만 등) | ✅ |
| HUSB-04-F04 | 급이 주기 자동 알림 | 설정한 주기 초과 시 알림 | ✅ |
| HUSB-04-F05 | 탈피 주기 통계 | 탈피 간격 평균, 추세 | 2차 |

## 3. 데이터 모델 (개념)

```
MyAnimal (내 생물)
├── id, userId, speciesId (→ Species 연결)
├── name, gender (MALE/FEMALE/UNKNOWN)
├── adoptionDate, birthDate
├── adoptionSource (PURCHASE/ADOPTION/BRED/OTHER)
├── morphId (→ Morph 연결, nullable)
├── photoUrl, currentWeight, currentLength
├── feedingCycleDays
├── status (ACTIVE/DECEASED/TRANSFERRED)
├── memo
└── createdAt, updatedAt

DiaryEntry (사육 일지)
├── id, animalId
├── type (FEEDING/SHEDDING/DEFECATION/HYDRATION/MEMO)
├── date, time
├── details (JSON: 타입별 상세 데이터)
│   ├── FEEDING: { foodType, amount, consumed: bool }
│   ├── SHEDDING: { completeness: FULL/PARTIAL/STUCK, note }
│   ├── DEFECATION: { condition: NORMAL/ABNORMAL, note }
│   └── HYDRATION: { type: WATER/MIST/BATH }
├── photoUrls[]
├── memo
└── createdAt

EnvironmentLog (환경 로그)
├── id, animalId
├── recordedAt
├── tempHot, tempCool, humidity
└── note

GrowthRecord (성장 기록)
├── id, animalId
├── recordedAt
├── weight (g), length (cm)
├── photoUrl
└── note

HealthRecord (건강 기록)
├── id, animalId
├── type (SYMPTOM/VET_VISIT/MEDICATION)
├── date
├── details (JSON: 타입별 상세 데이터)
│   ├── SYMPTOM: { symptoms[], description, photoUrls[] }
│   ├── VET_VISIT: { clinic, diagnosis, prescription, cost, nextVisit }
│   └── MEDICATION: { drugName, dosage, frequency, startDate, endDate }
└── createdAt

CalendarEvent (캘린더 이벤트)
├── id, animalId, userId
├── type (FEEDING/SHEDDING_EXPECTED/VET_APPOINTMENT/MEDICATION/CUSTOM)
├── date, time
├── title, description
├── recurring (boolean), recurringRule
├── reminderBefore (NONE/SAME_DAY/1_DAY/3_DAYS)
└── completed (boolean)
```

## 4. 백과사전-사육관리 연동 포인트

| 연동 | 설명 |
|------|------|
| 종 선택 → 사육가이드 자동 연결 | 등록 시 백과사전의 종을 선택하면 사육가이드(온도, 습도, 급이 정보) 자동 참조 |
| 환경 범위 기준 | 환경 로그에서 권장 범위 표시 시 백과사전 CareGuide 데이터 사용 |
| 급이 주기 기본값 | 종별 권장 급이 주기를 기본값으로 세팅 |
| 성장 비교 | (2차) 종 평균 성장 데이터와 내 생물 비교 |
