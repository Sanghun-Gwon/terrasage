## 2. 화면별 상세 기능

### ENCY-01: 생물 목록

**목적**: 사용자가 원하는 생물을 빠르게 찾을 수 있도록 검색·탐색 제공

**UI 구성 요소**:
- 상단 검색바 (학명/일반명/영어명 통합검색)
- 분류 필터: 대분류(파충류/양서류/절지류/소동물) → 중분류(목/과) → 소분류(속/종)
- 정렬: 인기순, 가나다순, 최신등록순
- 카드형 그리드 (썸네일, 일반명, 학명, 난이도 배지)
- 무한 스크롤 또는 페이지네이션

**기능 상세**:

| 기능 ID | 기능명 | 설명 | MVP |
|---------|--------|------|-----|
| ENCY-01-F01 | 통합 검색 | 학명, 일반명, 영어명으로 검색. 자동완성 지원 | ✅ |
| ENCY-01-F02 | 분류 필터 | 계층형 분류 체계로 필터링 (대>중>소분류) | ✅ |
| ENCY-01-F03 | 난이도 필터 | 사육 난이도별 필터 (입문/중급/상급) | ✅ |
| ENCY-01-F04 | 정렬 | 인기순, 가나다순, 최신순 | ✅ |
| ENCY-01-F05 | 북마크 | 관심 생물 저장 | ✅ |
| ENCY-01-F06 | 최근 본 종 | 최근 조회한 종 목록 표시 | 2차 |

**확장 고려사항**:
- 종 비교 기능 (2종 이상 선택하여 사육 조건 비교) → 2차
- AI 추천 ("나에게 맞는 생물 찾기") → 3차

---

### ENCY-02: 종 프로필 상세

**목적**: 하나의 생물 종에 대한 종합 정보를 탭 기반으로 제공

**UI 구성 요소**:
- 헤더: 대표 이미지, 일반명, 학명, 분류 경로, 난이도 배지
- 탭 네비게이션: 기본정보 | 사육가이드 | 모프/품종 | Q&A | 갤러리
- 사이드: 북마크 버튼, 공유 버튼, "내 생물로 등록" 바로가기

**기본정보 탭 내용**:

| 항목 | 설명 |
|------|------|
| 분류 체계 | 계 > 문 > 강 > 목 > 과 > 속 > 종 |
| 일반명 | 한국어명, 영어명 |
| 학명 | 이탤릭 표기 |
| 원산지 | 지도 표시 (2차에서 인터랙티브 맵) |
| 서식 환경 | 자연 서식지 설명 |
| 평균 수명 | 사육 시 / 야생 |
| 평균 크기 | 성체 기준 체장/체중 |
| 사육 난이도 | 입문 / 중급 / 상급 |
| CITES 등급 | 해당 시 멸종위기 등급 표시 |
| 법적 사육 가능 여부 | 국내 사육 가능 여부 및 관련 법규 안내 |

---

### ENCY-07: 정보 기여

**목적**: 사용자가 새로운 종을 등록하거나 기존 정보 수정을 요청

| 기능 ID | 기능명 | 설명 | MVP |
|---------|--------|------|-----|
| ENCY-07-F01 | 새 종 등록 요청 | 폼 작성 → 관리자 검수 큐 진입 | ✅ |
| ENCY-07-F02 | 정보 수정 제안 | 기존 페이지에서 "수정 제안" 버튼 → 변경점 diff | ✅ |

| ENCY-07-F04 | 기여 포인트 | 승인된 기여에 대한 포인트/배지 | 2차 |

## 3. 데이터 모델 (개념)

```
Species (종)
├── id, scientificName, commonNameKo, commonNameEn
├── taxonomy (kingdom ~ species)
├── origin, habitat, lifespan, avgSize
├── difficultyLevel (BEGINNER/INTERMEDIATE/ADVANCED)
├── citesLevel, legalStatus
├── thumbnailUrl
├── status (DRAFT/PUBLISHED/ARCHIVED)
└── createdAt, updatedAt

CareGuide (사육 가이드) — 1:1 with Species
├── enclosureType, enclosureSize, substrate
├── tempHotZone, tempCoolZone, tempNight
├── humidityMin, humidityMax
├── uvbRequired, photoperiod
├── feedType, feedFrequency, supplements
├── handlingLevel, cohabitationNote
└── updatedAt

Morph (모프) — N:1 with Species
├── id, name, geneticPattern (DOMINANT/RECESSIVE/CO_DOMINANT)
├── description, imageUrl
└── speciesId

SpeciesContribution (기여) — N:1 with User, Species
├── id, type (NEW_SPECIES/EDIT_SUGGESTION)
├── content (JSON diff)
├── status (PENDING/APPROVED/REJECTED)
├── reviewerNote
└── userId, speciesId, createdAt
```
