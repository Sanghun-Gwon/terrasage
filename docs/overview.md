# TerraSage 프로젝트 개요

생물 백과사전 및 사육 관리 플랫폼

---

## 핵심 기능

### 1. 생물 백과사전
- 생물학적 분류 체계 (계-문-강-목-과-속-종)
- 아종/변이 별도 관리 (검색 포함)
- 사육 난이도 1~10 (쉬움/보통/어려움)
- 확장 사육 정보 (온도, 습도, 먹이, 광량, 수명, 크기, 서식지, 번식)
- 갤러리 형식 이미지 (카테고리별 분류)
- 고급 검색 (조건 조합)
- 데이터: 국가기관 API 연동 검토 + 사용자 제안(관리자 승인)

### 2. 커뮤니티
- 주제별 게시판: 사육팁/노하우, 질문/답변, 자랑/인증, 자유게시판
- 게시글: 텍스트 + 이미지 혼합 지원
- 상호작용: 댓글/대댓글, 좋아요, 북마크, 신고
- 팔로우/구독: 사용자, 게시판, 키워드
- 회원 등급: 활동 기반 등급 시스템
- 검색: 검색엔진 스타일 통합 검색
- 알림: 풀 알림 (댓글/팔로우/멘션/인기글/키워드)

### 3. 개인 사육환경 관리
- 개체 등록: 백과사전 연동 + 직접 입력
- 관리 단위: 개별 관리 + 그룹(사육장/수조) 관리
- 데이터 기록: 수동 입력 + IoT 연동
- 기록 항목: 온도, 습도, 먹이, 광량, 토양/수질 농도, 탈피/번식 기록
- Grafana 스타일 대시보드 (트렌드 분석, 비교 차트)
- 데이터 공유: 선택적 공개

### 4. AI 기반 기능
- 스마트 알림 (스케줄 + 임계값 + 예측)
- 세팅 가이드: 개인 학습 + 커뮤니티/전문가 데이터 추천

### 5. 건강 진단
- 입력: 사진 + 증상 설명 (혼합 지원)
- AI 분석: 건강 상태, 원인, 해결책, 예방법, 관련 제품 추천
- 스마트 모니터링: 사육환경 기반 건강 위험 예측
- 건강 이력: 사육환경 관리와 통합
- 질병 DB: 종별 질병 정보 + 커뮤니티 사례 연동

### 6. 마켓플레이스
- 상품: 생물 개체, 사육용품, 먹이/영양제
- 판매자: 승인제 등록
- 거래: 직거래 + 경매 (즉결/역경매/비공개)
- 결제: 플랫폼 결제 (PG 연동)
- 배송: 판매자 직접 처리
- 리뷰: 별점 + 텍스트/사진 리뷰 + 신뢰도 점수
- 분쟁: 관리자 중재 시스템
